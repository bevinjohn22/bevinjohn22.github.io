# Bevin John — Portfolio

Live site: https://bevinjohn22.github.io

A single-page, project-first portfolio built with plain HTML and CSS. It has no build step or framework; a few lines of JavaScript power the contact popup.

## Files
- `index.html`: the whole site (layout, styles, and content)
- `resume.pdf`: the resume behind the "Resume (PDF)" button
- `favicon.svg`: the browser tab icon

## Updating
- **Resume:** upload a new `resume.pdf` with the same file name.
- **Projects or experience:** edit the matching section in `index.html`.

Changes go live on GitHub Pages about 1–2 minutes after each commit.
